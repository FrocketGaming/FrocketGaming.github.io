Snippets Feature Ideas
======================

HIGH IMPACT / SMALL EFFORT
---------------------------
1. Quick-copy on list items
   A small copy icon on each snippet row so you don't have to open the snippet to grab the code.
   High friction today for snippets you use constantly.

2. Tag autocomplete
   When typing in the tags input, suggest existing tags from your library.
   Prevents tag fragmentation (e.g. "python" vs "py" vs "Python").

3. Extension/language filter chips
   A row of clickable pills (JS · PY · SQL · TeX · ...) above the snippet list
   that filter by extension, independent of category.
   Useful when categories are language-agnostic.


HIGH IMPACT / MEDIUM EFFORT
-----------------------------
4. Snippet variables / placeholders
   Define {{variableName}} placeholders in snippet content.
   When you click "Use" or copy, a small modal prompts for each variable's value,
   substitutes them, and puts the result on the clipboard.
   Transforms snippets from static text into reusable templates.

5. Diff view in version history
   Right now history shows the old version but not *what changed*.
   A unified diff (added/removed lines highlighted) between the selected version
   and the current one would make history genuinely useful for reviewing changes.

6. Bulk operations
   Checkbox select on snippet list items → bulk delete, bulk move to category,
   or bulk export. Useful for cleanup and reorganization.


MEDIUM IMPACT / MEDIUM EFFORT
-------------------------------
7. Live HTML/CSS preview
   For .html and .css snippets, a "Preview" tab in the viewer that renders
   the code in a sandboxed <iframe>.

8. Export as Markdown cheat sheet
   Export all snippets in a category (or all favorites) as a single formatted
   .md file — name + description as heading, fenced code blocks.
   Great for sharing reference sheets or printing.

9. Search operators
   Power-user syntax in the search box: tag:auth, ext:py, fav:true.
   The search infrastructure is already in place, just needs operator parsing.


NICE TO HAVE
-------------
10. Snippet aging indicator
    Subtle visual cue on snippets not opened/copied in 90+ days,
    so you can audit stale content.

11. Copy count badge on list items
    Tiny number showing copy count, visible in the list.
    Makes it easy to spot most-used snippets without changing the sort.

12. Code formatter button
    A "Format" button in the edit modal that auto-indents content
    (using a formatter like prettier standalone) for JS/HTML/CSS/JSON.


TOP PICKS
----------
- Snippet variables (#4) — most distinctive, natural evolution from templates
- Diff view in history (#5) — highest-value fix to an existing feature
