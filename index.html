Quality-of-Life Developer Tools

A collection of browser-based utilities for everyday development tasks. Everything runs locally in your browser — no sign-ups required.

Txt Formatter
Transform, format, and manipulate text — lists, case conversion, JSON, find & replace, and more.
Snippets
Store and organize code snippets locally. Sync across devices with Google sign-in.
To-Do List
Manage tasks with categories, priorities, and local storage persistence.
CSV Viewer
View, sort, and filter CSV data in an interactive table with SQL query support.
Regex Tester
Test regular expressions in real time with match highlighting and group capture details.
Image Editor
Annotate, crop, resize, and export images with blur/redact support.
Chart Builder
Build interactive charts from CSV or JSON data with customizable styles and PNG export.
Cron Builder
Build and validate cron expressions with a visual editor and next-run preview.
Timezone
Compare times across multiple timezones and convert between them.
Text Diff
Compare two texts and see additions, deletions, and modifications with word-level highlighting.
